# مهامي — تطبيق To‑Do بـ Flutter مع تحديث عن بعد

تطبيق مهام (عربي RTL) تقدر تحدّثه **من GitHub** ويصل التحديث للمستخدمين بدون ما يحمّلوا التطبيق من جديد.

## 3 طرق للتحديث عن بعد

| الطريقة | ماذا تغيّر | كيف | يحتاج تثبيت؟ |
|---|---|---|---|
| **① إعدادات فورية** | العنوان، الألوان، الوضع الليلي، الإعلانات، المهام المقترحة، إظهار/إخفاء الميزات، وضع الصيانة | عدّل `remote/config.json` وارفعه | ❌ لا — يظهر خلال دقائق |
| **② تحديث الكود (أندرويد)** | أي شيء في `lib/` | ارفع الكود → GitHub Actions يبني APK وينشره | التطبيق يكتشفه ويُنزّله بنفسه، المستخدم يضغط "تثبيت" فقط |
| **③ نسخة الويب** | كل شيء | ارفع الكود → ينشر تلقائياً على GitHub Pages | ❌ لا — تتحدث مع أول تحديث للصفحة |

### ① تعديل الإعدادات (الأسرع)
افتح `remote/config.json` على GitHub ← ✏️ Edit ← غيّر مثلاً:
```json
"primary_color": "#E91E63",
"announcement": { "enabled": true, "text": "عرض جديد!", "color": "#4CAF50" }
```
**زِد `config_version` بواحد** ثم Commit. التطبيق يجلب الإعدادات عند فتحه، وعند الرجوع إليه، وكل دقيقتين، وعند السحب للأسفل.
> ملاحظة: خوادم raw.githubusercontent.com قد تخزّن الملف مؤقتاً حتى ~5 دقائق.

### ② تحديث كود التطبيق
1. عدّل أي ملف في `lib/` وارفعه (`git push`).
2. Workflow **Android – بناء ونشر التحديث** يبني APK موقّع، ينشره في Releases، ويحدّث `remote/version.json`.
3. أي جهاز عليه التطبيق يظهر له "إصدار جديد" ← ينزّل ← يضغط تثبيت. بياناته (المهام) تبقى كما هي.

لتحديث **إلزامي** أو كتابة ملاحظات: Actions ← Android ← Run workflow.

## ملفات مهمة
```
lib/config.dart                 روابط GitHub
lib/services/remote_config.dart جلب الإعدادات البعيدة + التخزين المؤقت
lib/services/updater.dart       فحص وتنزيل وتثبيت التحديث
remote/config.json              ← عدّل هذا للتحديث الفوري
remote/version.json             ← يحدّثه GitHub Actions تلقائياً
```

## Secrets المطلوبة (مضبوطة مسبقاً)
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` — مفتاح التوقيع لازم يبقى نفسه دائماً، وإلا أندرويد يرفض التحديث.
**احتفظ بنسخة احتياطية من ملف المفتاح.**

## التشغيل محلياً
```bash
flutter pub get
flutter run
```

## ترقية اختيارية: Shorebird (تحديث كود Dart بصمت)
لو تبي تحديث كود Dart بدون حتى نافذة التثبيت، استخدم [Shorebird](https://shorebird.dev):
```bash
shorebird login && shorebird init
shorebird release android      # مرة واحدة
shorebird patch android        # لكل تحديث → يصل بصمت عند إعادة تشغيل التطبيق
```
